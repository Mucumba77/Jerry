# Code of Conduct

Jerry welcomes participation from everyone. Please be respectful and constructive; harassment, discrimination, threats, unwanted sexual attention and publishing private information without permission are not acceptable. Focus on behavior and technical merit, assume good intent where reasonable, and respect maintainers' decisions.

Project maintainers may edit or remove comments, reject contributions, or limit participation when necessary. Report inappropriate behavior privately to the repository owner through their GitHub profile. Do not post sensitive personal information in a public issue. Reports will be handled as discreetly as practicable.
