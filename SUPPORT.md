# Support

Start with the [English Wiki](https://github.com/Mucumba77/Jerry/wiki/EN-Home) or [German Wiki](https://github.com/Mucumba77/Jerry/wiki), especially the troubleshooting page. Search existing issues, then use the appropriate [issue form](https://github.com/Mucumba77/Jerry/issues/new/choose) for reproducible problems or feature requests. This community project does not promise response times or commercial support.

Do not post credentials, private SQL, production data or sensitive logs. Report vulnerabilities privately via the [security advisory form](https://github.com/Mucumba77/Jerry/security/advisories/new); see [SECURITY.md](SECURITY.md).
