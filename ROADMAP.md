# Roadmap

This is a list of possible directions, not a release commitment. Priorities and scope can change based on feedback and maintainer capacity.

- Improve automated platform, browser and provider compatibility testing.
- Review interface translations with native speakers and improve accessibility.
- Improve documentation and troubleshooting for JDBC drivers, application frameworks and deployment.
- Maintain dependencies and respond to security reports.
- Explore integrations requested by operators, subject to performance and security review.

Use the [issue tracker](https://github.com/Mucumba77/Jerry/issues) to propose work or ask about contributing.
